# Jesse Weigel

I build AI agent systems, developer tools, and full-stack products with TypeScript, Python, and React. My work focuses on agent orchestration, evaluation, and making complex systems easier to inspect.

[Portfolio](https://jesseweigel.com) · [Résumé](https://jesseweigel.com/resume) · [LinkedIn](https://www.linkedin.com/in/jesseweigel/)

## Selected projects

- **[Toryo](https://github.com/JesseRWeigel/toryo)** — TypeScript orchestration for coding agents, with evidence-bound review gates, configured deterministic checks, and recoverable Git checkpoints. Includes tests using real Git transactions.
- **[Tenshu](https://github.com/JesseRWeigel/tenshu)** — A local React/TypeScript dashboard with a Hono API, WebSocket updates, and typed views of agent and session activity. Includes tests and a simulated demo mode.
- **[Minecraft Agent Swarm](https://github.com/JesseRWeigel/minecraft-agent-swarm)** — A local Ollama/Mineflayer multi-agent system in TypeScript, with shared context, persistent memory, telemetry, and a separate experimental evaluation track.
- **[BattleMath](https://github.com/JesseRWeigel/battlemath)** — A React/TypeScript math practice game with adaptive difficulty, hints, daily challenges, and local progress tracking.
